# TRQ Trading — بوت تداول عقود KuCoin الآجلة

بوت شبكة + صيد + جني ربح يعمل بالكامل في المتصفح/الجوال:

- بيانات لحظية مستمرة عبر WebSocket (سعر + دفتر أوامر + صفقات)
- شارت شموع بإطارات زمنية ومناطق الدخول/الجني/المتوسط/التصفية
- وضع ورقي (محاكاة) ووضع حقيقي بمفاتيح API (تداول فقط)
- يعمل كتطبيق أندرويد (APK) — يُبنى تلقائيًا عبر GitHub Actions

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000 — البروكسي المحلي `/kucoin` يحل مشكلة CORS.

## تحميل تطبيق الجوال (APK)

كل دفعة (push) إلى فرع main تبني APK تلقائيًا وتنشره في صفحة **Releases**.
حمّل `app-debug.apk` على جوالك وثبّته مباشرة.

## بنية المشروع

| الملف | الوظيفة |
|---|---|
| `src/engine.ts` | محرك البوت: شبكة + صيد + جني + انعكاس + هروب من التصفية |
| `src/ws.ts` | قناة WebSocket المستمرة مع KuCoin + إعادة اتصال تلقائية |
| `src/Chart.tsx` | الشارت الاحترافي: شموع + إطارات + مناطق |
| `src/App.tsx` | الواجهة العربية |
