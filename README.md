# تطبيق TRQ لل تداول الشبكي - KuCoin Futures

هذا المستودع يحتوي على ملفات تطبيق TRQ (الإصدار 1.5) الذي يتصل بمنصة كوكوين فيوتشرز **اتصالاً مباشراً** من جهازك، بدون أي خوادم وسيطة.

## الملفات

| الملف | الوصف |
|---|---|
| index.html | التطبيق الكامل (الإصدار 1.5) - هذا هو الملف المطلوب |
| direct-test.html | صفحة اختبار الاتصال المباشر بالمنصة (REST + WebSocket) |
| worker.js | وسيط Cloudflare احتياطي، اختياري، لا يحتاجه أغلب المستخدمين |

## خطوات التحميل والتشغيل

1. افتح ملف index.html من هذا المستودع.
2. اضغط زر **Download raw file** (أعلى الملف على الجهاز) أو اضغط زر **Raw**.
3. احفظ الملف باسم **index.html**.
4. ارفع الملف إلى موقعك على Neocities بنفس الاسم ليستبدل النسخة القديمة (اضغط Upload ثم أكّد الاستبدال).
5. افتح التطبيق من الجوال وادخل إلى **الإعدادات** وتأكد أن رقم الإصدار المعروض هو **1.5**.
6. ابحث عن الشارة الخضراء **أسعار حية** في أعلى الشاشة - وجودها يعني أن الاتصال المباشر بالأسعار يعمل.
7. أدخل مفاتيح API واضغط **ربط المنصة**.

## شروط مفاتيح API (مهم)

- أنشئ المفتاح من kucoin.com ثم API ثم تفعيل صلاحية **Futures**.
- صلاحية **تداول فقط، بدون سحب** أبداً.
- بدون تقييد عنوان IP.

## إذا ظهرت شارة «أسعار غير حية»

افتح ملف direct-test.html واضغط **ابدأ الاختبار** لمعرفة أيهما محجوب في شبكتك: الطلب المباشر أم البث المباشر. إن كان الاثنان محجوبين فالحل تشغيل worker.js على Cloudflare (مجاني، 10 دقائق، مرة واحدة) ووضع رابطه في حقل **رابط الوسيط** داخل إعدادات التطبيق.
